# Portfolio Summary

RAGOps Enterprise Copilot demonstrates an applied AI engineering slice with:

- Tenant-aware enterprise RAG.
- Deterministic local LLM test provider.
- Optional OpenAI and Azure OpenAI provider adapters.
- Typed multi-agent workflow.
- Prompt-injection and PII controls.
- Synthetic CRM plus document retrieval.
- Executable retrieval and security evaluation.
- Docker hardening and CI evidence generation.
- A resumable, bounded Codex automation loop.

The project is intentionally synthetic and does not claim production readiness
without replacing local fixture adapters with managed storage, observability,
identity, and deployment services.
